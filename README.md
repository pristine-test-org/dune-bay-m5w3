# Dune Bay: Monorepo · Vercel and Render

A monorepo with three apps on two hosts: `dropwort-g4h` and `elecampane-j5k` on **Vercel**,
`figwort-l6m` on **Render** (a static site). Preview links are **public** on both. Static Vite +
TypeScript, no framework. The page reads a live list from the shared Supabase test project.
